# World templates

Every daily project references a compact, pre-generated, bounded template. Prefer original BadgerBots worlds. Properly licensed third-party worlds may be imported only with a completed license record.

Each world package must contain:

- immutable template archive;
- `world.yaml` with version, spawn, border, reset policy, expected resource budget, and checksum;
- `world-license.yaml` with creator, source URL, license, allowed modifications/distribution, attribution, and reviewer;
- screenshots for curriculum selection;
- validation report for server version and forbidden content.

Never commit active camper worlds or backups.
