# BadgerBots Host

Planned Tauri 2 desktop application for the teacher laptop. It owns Paper lifecycle, health checks, world instances, plugin updates, local backups, logs, outbound cloud pairing, Windows sleep inhibition while active, and a polished first-run wizard.

Target the assumed minimum teacher machine conservatively: Windows 10, Intel i5/i7, 16 GB RAM, Wi-Fi, plugged in. Load tests must cover 25 campers; offer guarded degraded modes if hardware cannot sustain the preferred world strategy.
