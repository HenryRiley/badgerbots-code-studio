# Curriculum schema

Checkpoint 1 implements versioned, source-gated track, project, benchmark, and world-template schemas. Checkpoint 8 adds a provider-neutral authoring lifecycle for immutable revisions, optimistic conflicts, preview, duplication, review, owner-only publication, asset/source provenance, canonical starter-program validation, and tolerant structural/runtime/manual benchmarks.

The toolbox policy is fixed to `complete-searchable-library`; instructional groups suggest blocks
but cannot create an allowlist. Publication fails while any referenced source, asset, starter
program, or world template is unverified.

The in-memory service exists for deterministic tests and the local browser lab. It is not
authenticated persistence. No lesson prose, screenshots, maps, or slide references were invented
or imported.
