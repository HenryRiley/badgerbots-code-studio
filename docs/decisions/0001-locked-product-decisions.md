# ADR 0001: Locked product decisions

Status: accepted for initial planning.

- Minecraft only; ignore Roblox.
- One teacher-laptop centralized server per location.
- Maximum 20-25 students on Wi-Fi; assumed teacher laptop Windows 10, Intel i5/i7, 16 GB RAM.
- Hybrid cloud website plus local Minecraft execution.
- Polished teacher and student installers are part of the first usable product.
- Conservative modern Minecraft/Paper release chosen by compatibility spike; do not remain on 1.16.5 by default.
- Compact daily world templates, private to campers by default; teacher world always loaded.
- Blockly is the student editor foundation; full library always available.
- Instructor-only restricted Java-style mode must round-trip to blocks.
- Safe controlled API only; no arbitrary Java execution.
- Both curriculum tracks are in scope; Sheep City is the first vertical slice.
- One session owner and assistant instructors.
- Camper data is temporary; device/Minecraft username mapping persists.
- BadgerBots branding from the beginning; original interface and assets.
